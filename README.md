# Tentzhen

An open-source lab instrument built from generic parts, for people who can't afford the real thing.
Pronounced "TENT-zhen" (like "tension").

A two-channel digitizer and signal generator on a Colorlight i9 (Lattice ECP5) board, with cheap
AD9226 ADC modules and a custom analog front end. Target cost is roughly $150–200 in parts.

**Status:** nothing works yet. Phase 1 (bring-up) has not started.
