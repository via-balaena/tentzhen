# Tentzhen

Economical electronics projects that take advantage of the electronics surplus, to help people
survive, and eventually thrive, in the AI economic transition happening now. Pronounced
"TENT-zhen" (like "tension").

Project #1 is a bench of open, verifiable instruments built from cheap generic parts. Its
instrument #1 is a two-channel digitizer and signal generator in the Red Pitaya class, on a
Colorlight i9 (Lattice ECP5) board with AD9226 ADC modules and a custom analog front end.

Every claim this project makes says how it is known: proven, checked, tested, measured,
trusted, or unknown.

**Status:** planning. Nothing works yet.
