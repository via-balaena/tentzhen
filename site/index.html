U2

A neural network hardwired into an FPGA

LittleBit × Taalas: weights well under one bit each, built into the logic.

FPGA
Colorlight i9 · Lattice ECP5 LFE5U-45F
MODEL
MLP 784 → 256 → 128 → 10 · MNIST first
BITS
Binary low-rank factors and scales, after LittleBit
ROMS
Weights in LUT logic · the same bits in block RAM
FOR
Simulations with trained agents: SocialJax, Concordia · local AI companions

measuredOn a Colorlight i9 at 50 MHz, the network at r = 16 scored MNIST's first 1,000 test images exactly as the golden model does, 1,219 clocks each (2026-11-23-i9-littlebit-network).

tested97.17 % of MNIST's 10,000 test images right, at 0.125 bits a weight in its first layer; the gateware scores all 10,000 as the golden model does.
